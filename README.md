# AutoTube

Видео на парковке, звук в дороге — для Android Auto.

## Как это работает
- **Видео (телефон):** официальный плеер YouTube (IFrame) в `MainActivity`. Работает только когда GPS показывает, что вы стоите (< ~3.6 км/ч). Нет GPS, нет разрешения или есть движение — видео блокируется (fail-safe).
- **Аудио (Android Auto):** `PlaybackService` (Media3 `MediaLibraryService`) — каталог и управление отображаются на экране магнитолы. Android Auto не даёт сторонним приложениям выводить видео, поэтому в машине — только аудио.
- Источники звука задаются в `Library` (`PlaybackService.kt`). По умолчанию — демо-треки; подставьте свои подкасты/файлы/лицензированные потоки.

## Ограничения (важно)
- Условия YouTube запрещают извлекать аудио/видеопотоки в обход официального плеера, поэтому проект этого **не делает**.
- Видео в движении намеренно не поддерживается: это опасно и во многих странах запрещено.

## Сборка
1. Android Studio (Koala+) → Open → папка проекта (Studio сама создаст Gradle wrapper), либо `gradle wrapper && ./gradlew assembleDebug`.
2. GitHub Actions (`.github/workflows/build.yml`) собирает debug-APK при каждом push.

## Запуск в Android Auto
1. На телефоне: Android Auto → Настройки → несколько раз нажать «Версия» → включить режим разработчика → меню ⋮ → «Неизвестные источники».
2. Установите APK, подключите телефон к машине (или Desktop Head Unit) — AutoTube появится в разделе «Музыка».
